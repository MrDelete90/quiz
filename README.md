# Interactive Quiz Application

A 5-question multiple-choice quiz built with HTML, CSS and JavaScript. It shows one question at a time and displays the final score at the end.

## Features
- One question at a time with four options
- Score calculation
- Final result shown at the end
- Blue, white and gold design

## Technologies Used
HTML, CSS, JavaScript

## How to Run
Open `index.html` in a browser.
